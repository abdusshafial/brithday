HAPPY BIRTHDAY WEBSITE

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Open index.html.
4. Right-click and choose "Open with Live Server" (recommended), or double-click index.html.

CUSTOMIZE
- Change "Superstar!" in index.html to the birthday person's name.
- Edit the birthday messages directly in the HTML.
- The music button creates a simple melody using browser audio (no music file needed).
- Replace the three memory cards with your own memories/photos if you want.

This is a front-end website made with HTML, CSS and JavaScript. It does not need a server or database.
